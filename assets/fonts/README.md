# REBOUND typography

- Rajdhani Bold: title and UI headings. Copyright 2014 Indian Type Foundry.
- Space Grotesk: 400-weight subtitle and interface text; 600-weight menu buttons. Copyright 2020 The Space Grotesk Project Authors.

Both fonts are distributed under the SIL Open Font License 1.1. Unmodified font binaries and their complete licenses are bundled here; no system font installation or network access is needed at runtime.

Sources: [Rajdhani](https://github.com/google/fonts/tree/main/ofl/rajdhani), [Space Grotesk](https://github.com/google/fonts/tree/main/ofl/spacegrotesk).

Title: 86 px with 4 px extra glyph spacing. Subtitle: 20 px with 1 px extra glyph spacing. Existing menu/HUD sizes and color palette are retained; larger HUD headings use Rajdhani Bold and body text uses Space Grotesk. ui_typography.tres changes fonts only and retains Godot's existing widget styling.
